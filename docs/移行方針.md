# OBFALL-PROJECT 移行方針

## 概要

Laravel 8（Blade + Laravel Mix）製のWebサイト https://obfall.com/ を React + TypeScript に完全移行する。

- 現行: ロリポップ（Laravel 8 / MySQL 8）+ ムームードメイン
- 移行後: Vercel + ムームードメイン（DNSのみ流用）
- 調査結果は docs/migration-assessment.md を参照（タスク1の成果物、2026-09-21）

## 技術選定

### 確定

- フレームワーク: Next.js（React + TypeScript、App Router）
    - 静的ページはサーバーコンポーネント、フォームはクライアントコンポーネント + Server Actions
- ホスティング: Vercel
- CSS: 当面 Bootstrap 5 を npm で導入して維持する（置換の可否は全画面の方針として後で決める）
- DB: Neon（Postgres、Vercel Marketplace 経由）
    - 現行は MySQL のため、スキーマ変換が必要（DATE_FORMAT、ON UPDATE CURRENT_TIMESTAMP、utf8mb4 照合順序は Postgres に直接移せない）
    - 日付整形は SQL 側ではなくアプリ側（Intl / dayjs）で行う
    - 接続: 読み取りは `@neondatabase/serverless` の HTTP（`neon()`）、書き込み・トランザクションは `Pool`
- ORM: Drizzle ORM（drizzle-kit でスキーマ管理・マイグレーション）
- 公開ページの配信: ISR（お知らせ一覧・詳細・トップ）+ 管理画面の保存時に `revalidatePath` でオンデマンド再検証
- バリデーション: Zod（クライアント・サーバーで同一スキーマを共有。PasswordRule 等は Zod に移植）
- メール: Resend
    - 現行と同じテキストメール（React Email は使わない）
    - 送信元ドメイン obfall.co.jp の SPF / DKIM / DMARC をムームードメインの DNS に設定
    - 宛先・差出人アドレスは環境変数化する（ハードコードしない）
- 問い合わせフォームのスパム対策: Cloudflare Turnstile + ハニーポット

## 共通ルール

- 対象ディレクトリ: `./`（既存 Laravel）と `./web/`（新規 Next.js）
- 読み込み除外: `vendor/`, `node_modules/`, `public/backend/vendor/`, `public/js/app.js`, `public/css/app.css`, `public/image/`, `public/uploads/`, `storage/`, `bootstrap/cache/`, `*.log`
- `public/uploads/` はユーザーアップロード物の可能性があるため中身を開かない
- 本番環境・本番DBには一切アクセスしない
- 既存の Laravel 側コードは変更しない（移行完了まで現行の参照元として保持する）
- 不明点は推測で進めず、「確認事項」として成果物に列挙する
- 日本語で出力する
